# S20 기기 정보

## 접속 정보
- SSH alias: `ssh YOUR_S20_HOST`
- 실제: `geonhee_s20@YOUR_S20_IP -p 8022`
- Tailscale IP: `YOUR_S20_IP`

## 주요 경로 (S20 내부)
- 홈: `/data/data/com.termux/files/home/`
- openclaw: `~/.openclaw/`
- workspace: `~/.openclaw/workspace/`
- LONGMEMORY: `~/LONGMEMORY/`

## 서비스
- **OpenClaw** (포트 18789): `pkill -f openclaw && openclaw start`
- **code-server** (포트 8080): `bash ~/start-code-server.sh`
  - 브라우저 접속: `http://YOUR_S20_IP:8080`
  - 맥 alias: `s20-code`
- **sshd** (포트 8022): `sshd` (꺼져있으면 SSH 불가)

## 파일 수정 방법
- S20 직접 수정: `ssh YOUR_S20_HOST "cat > ~/경로 << 'EOF' ... EOF"`
- 맥→S20 전송: `scp 파일 YOUR_S20_HOST:~/경로`
- 파일 보기: `s20-code` (브라우저 VSCode)

## 주의사항
- macOS 26에서 macFUSE/sshfs 미지원
- VS Code Remote SSH 미지원 (glibc 없음) → code-server 사용
- 맥 로컬 `/Users/geonhee/s20/`는 자동 동기화 안 됨 (참고용)
